```yaml

  package="${{ steps.contract.outputs.package }}"   # line 205 — lost after this line
  echo "Using validated Android package: $package"
  bash ...smoke-android-apk.sh ... "$package" ...   # line 207 — $package is EMPTY
  ...
  CHORESCORE_E2E_PACKAGE="$package" ...              # line 209 — $package is EMPTY
```

`smoke-android-apk.sh` line 3 requires a non-empty `$2` (`package="${2:?package}"`) and aborts with an empty argument.
