## Root cause (confirmed)

The `android-emulator-runner` action (rev `a421e43855164a8197daf9d8d40fe71c6996bb0d`) executes each line of the `script:` input as a separate `sh -c` process (`lib/script-parser.js` splits by newlines; `lib/main.js` runs `exec.exec('sh', ['-c', line])` per line). The `$package` variable set on line 1:

```yaml
script: |
  package="${{ steps.contract.outputs.package }}"
  echo "Using validated Android package: $package"
  bash "$GITHUB_WORKSPACE/.github/scripts/smoke-android-apk.sh" "${{ steps.build.outputs.apk }}" "$package" "$RUNNER_TEMP/v2-smoke"
  ...
```

...does not persist to line 3. The smoke script receives an empty `$2` and aborts on `${2:?package}` with `smoke-android-apk.sh: line 3: 2: package` (exit 1), failing the release job before the Android golden path E2E can run.
