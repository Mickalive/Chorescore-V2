## Five mustFix findings (repair required)

### F1 — Share sheet non-functional on Android (core deliverable broken)

**Path**: `src/infrastructure/local/LocalSystemShareAdapter.ts`
**Problem**: Adapter uses `navigator.share` (Web Share API), absent in React Native/Hermes on Android. `isAvailable()` always returns false on native; `share()` always returns `{completed:false}`. The share sheet never opens on APK.
**Required fix**: Implement with `Share.share` from react-native (or expo-sharing). Keep `isAvailable()` honest. Add test verifying native API delegation.
**Verification**: On Android APK, sharing from Score and history opens the native share sheet.

### F2 — ShareCard is dead code (visual sharing absent)

**Path**: `src/ui/components/ShareCard.tsx`
**Problem**: Component is never rendered in any screen. Only `generateShareText` is used — sharing produces text only, not visual cards as required by acceptance.
**Required fix**: Integrate ShareCard into share flow: render it and share as image via SystemShareGateway (`files` option), or document why visual sharing is deferred.
**Verification**: Share from Score/history produces a visual card (image) via native share sheet.

### F3 — Visual evidence gallery absent (QG-4)

**Path**: repository root (gallery directory)
**Problem**: Required visual evidence gallery per QG-4/DESIGN_BRIEF is completely absent. Zero screenshots in repository or trusted verification output.
**Required fix**: Produce the gallery (12 screens from DESIGN_BRIEF) as reproducible audit artifacts.
**Verification**: Gallery artifacts exist and are reproducible from the accepted tree.

### F4 — WCAG AA contrast failure (accessibility)

**Path**: `src/ui/design-system/theme.ts`
**Problem**: `textSecondary` #81B29A and `textMuted` #A8A8B3 fail AA (4.5:1) on all surfaces (2.03–2.40:1). `warning`/surface = 2.97. `primary`/background = 4.47. Test only checks `colors.text` pairs.
**Required fix**: Darken `textSecondary`/`textMuted`/`warning`/`primary` to ≥4.5:1 on all surfaces. Extend test to all used pairs.
**Verification**: Automated contrast check passes WCAG AA for all used text/surface pairs.

### F5 — False push notification display (QG-1 honest product)

**Path**: `app/options/personal.tsx`
**Problem**: Options shows "Notifications push: Activées", "Rappels de tâches: Activés", "Nouvelles assignations: Activées" while `LocalNotificationAdapter.isAvailable()` = false. Violates QG-1 (no fake product presented as active).
**Required fix**: Display honest states ("Non configuré" / "Indisponible") or wire to real adapter availability.
**Verification**: Options notification states match actual adapter availability.
