### Finding: No Real Local Persistence

- **Problem**: All repositories (entries, persistentTasks, chronoTimer) are `InMemory*Repository` — pure in-memory Maps with no disk persistence. On a real app restart, all data is lost.
- **Evidence**: `AppContext.tsx` lines 60-70 instantiate only `InMemory*Repository`. No `AsyncStorage`/`SecureStore`/`MMKV`/`sqlite` usage anywhere in `src/` or `app/`.
- **Tautological test**: The chrono resume test reads `getChronoState()` twice from the same in-memory map — never simulates an app restart.
- **Violated criterion**: "Local persistence and chrono resume work" (acceptance), "local persistence" (scope).

### Required Repair

1. Replace `InMemoryEntryRepository` with an AsyncStorage-backed `PersistentEntryRepository` (or similar)
2. Replace `InMemoryPersistentTaskRepository` with AsyncStorage-backed persistence
3. Replace `InMemoryChronoTimerRepository` with AsyncStorage-backed persistence
4. Update `AppContext.tsx` to use persistent repositories
5. Add a non-tautological persistence test: create entries + start chrono → recreate repository instance → verify data survives
6. Ensure all existing 183 tests still pass
