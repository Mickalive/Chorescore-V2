## Findings resolved this cycle

### F1 — Native share sheet broken on Android — FIXED
The adapter now uses React Native's built-in `Share.share({message})` for text content on native platforms, which correctly opens the native share sheet with plain text (no file URI needed). For file/image content it uses `expo-sharing` `shareAsync` with a valid `file://` URI from the cache directory. The prior broken path (passing plain text to `shareAsync`) is removed.

### F2 — ShareCard dead code — FIXED
`ScoreScreen` now renders a hidden `ShareCard` component and captures it as a PNG via `react-native-view-shot` `captureRef`, copies it to the cache directory, and shares it through the file path of `SystemShareGateway`, with a text fallback. The ShareCard is no longer dead code.

### F4 — WCAG AA contrast fails — FIXED
`textMuted` was darkened from `#7A7A87` to `#606070` and `warning` from an earlier value to `#7A5614`. Independent computation confirms all text/surface pairs pass WCAG AA 4.5:1. The contrast test was extended to cover textMuted and warning on all surfaces.
