DESIGN_BRIEF "Galerie de référence obligatoire" and QUALITY_GATES QG-4 require at least 12 reproducible screen captures (connexion, racine foyers, Ajouter Premium, Ajouter Free + archive, Score Premium, Score Free, To-do Premium, mini-form complétion, To-do Free, upsell historique, Options, share card) plus an empty/error state, kept as audit artifacts. No gallery/evidence/screenshot/capture directory or image artifact exists in the candidate diff or repository. Structural assertions are not visual evidence.

### Fixed

**F1 — Native share sheet now opens on Android.**
The adapter now uses React Native's built-in `Share.share({message})` for text content on native platforms, which correctly opens the native share sheet with plain text (no file URI needed). For file/image content it uses `expo-sharing` `shareAsync` with a valid `file://` URI (from `cacheDirectory`), which is the correct usage. The prior broken path (passing plain text to `shareAsync`) is removed. Note: the test coverage requirement (asserting the native API is invoked with a valid file URI) is not fully met — the Section 9 tests still only check `isAvailable()` and `typeof boolean` — but the functional fix is correct.

**F2 — Visual ShareCard is now integrated.**
`ScoreScreen` now renders a hidden `ShareCard` (off-screen) and captures it as a PNG via `react-native-view-shot` `captureRef`, copies it to the cache directory, and shares it through the file path of `SystemShareGateway`, with a text fallback. The ShareCard is no longer dead code. Minor concern: the hidden card uses `opacity: 0`, which may yield a blank capture on some platforms; this is a runtime behavior not verifiable without a device and does not block this decision.

**F4 — WCAG AA contrast now passes.**
`textMuted` (#606070) and `warning` (#7A5614) were darkened. Independent computation: textMuted/background 5.86, textMuted/surface 6.17, textMuted/surfaceAlt 5.54; warning/background 6.29, warning/surface 6.63, warning/surfaceAlt 5.95; textOnPrimary/primary 4.71 — all ≥ 4.5:1. The contrast test was extended to cover textMuted and warning on all surfaces.
