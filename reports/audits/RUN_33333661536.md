## Résolution du finding ciblé

### F4 — Régression demo-premium : `getAccountEntitlement` incohérent avec `createHousehold` ✅

**Problème (audit 33330593679) :** en mode demo-premium (mode par défaut de l'app), `getAccountEntitlement` retournait `canCreateFreeHousehold=false` après la création du premier foyer, désactivant le bouton « Créer un foyer » alors que `createHousehold` autorise toujours la création (bypass demo-premium). La démo ne permettait plus d'explorer/auditer la capacité Premium multi-foyers.

**Correctif appliqué (`src/infrastructure/local/LocalEntitlementAdapter.ts`) :**
- `getAccountEntitlement` résout d'abord `ownedFreeHouseholdId`/`ownedHouseholdCount` depuis `AccountRepository` (une seule consultation, plus de duplication de code entre les deux modes) ;
- en **demo-premium** : `canCreateFreeHousehold: true` constant — cohérent avec le bypass de `createHousehold` — tout en rapportant `ownedFreeHouseholdId` exact pour l'état UI ;
- en **demo-free** : `canCreateFreeHousehold = (ownedFreeHouseholdId === null)` — règle un-foyer-gratuit conservée.

**Test d'acceptation mis à jour (`__tests__/application/V2-01-acceptance.test.ts`, section 15) :** le test codifie désormais le comportement corrigé — demo-premium : `canCreateFreeHousehold=true` + `ownedFreeHouseholdId=1er foyer` après création ; bascule demo-free : `canCreateFreeHousehold=false` + `ownedFreeHouseholdId` conservé + second foyer rejeté. Le test précédent codifiait la régression (assertion `false` en demo-premium) ; il a été corrigé dans le sens de la correction exigée par le finding.

**Vérification indépendante (scénario déterministe reproduit hors de la suite du Builder) :** mode demo-premium, utilisateur créé → avant création `true`/`null`/`0` ; après 1er foyer `true`/`h1`/`1` ; 2e `createHousehold` réussit ; `canCreateFreeHousehold` toujours `true` ; `canCreateHousehold` `true` ; bascule demo-free → `false` + rejet du 2e foyer ; retour demo-premium → `true` sans perte de données. Tous les points de la vérification exigée par le finding sont satisfaits.

**Statut : corrigé et vérifié.**
