### Research Analytics Plane

9. **Query budget** (`queryBudget.ts`): Rate limits per minute (10) and per day (500), max dimensions per query (3), max time range (24 months), min cohort size (5). Sliding window for per-minute rate limiting. Daily reset logic. Custom configuration supported.

10. **Differential privacy** (`differentialPrivacy.ts`): Laplace mechanism: `noise = -scale * sign(u) * ln(1 - 2*|u|)` (correct inverse CDF). Gaussian mechanism: `sigma = sensitivity * sqrt(2 * ln(1.25/delta)) / epsilon` (correct (ε,δ)-DP formula). Box-Muller transform for Gaussian sampling. Budget tracking with configurable epsilon/delta. Array noise addition for histogram queries. Budget reset capability.

11. **Consent policy** (`consentPolicy.ts`): Four jurisdiction policies (EU-GDPR, US-CCPA, CH-DSG, UK-GDPR) with purpose-based consent requirements. EU-GDPR requires explicit consent for research/anonymized data products; US-CCPA uses opt-out model. Consent recording, checking, and withdrawal. `canProcessData()` combines policy requirements with consent state. Retention periods per jurisdiction. Architecture does not presuppose a single legal basis.

12. **Buyer contracts** (`buyerContracts.ts`): `reIdentificationProhibited`, `redistributionProhibited`, and `commercialUseProhibited` are ALWAYS `true` — hardcoded, not configurable. Audit rights granted. Re-identification reporting required. Purpose validation per contract. Contract revocation supported.

13. **Audit/export log** (`auditLog.ts`): `InMemoryAuditExportLog` records every external release with provenance (pipeline version, taxonomy version, transformations, gate version, differential privacy applied), gate check result (approved, violation count, risk score), buyer contract reference, household count, and time range. Query by product or buyer.

14. **PrivacyReleaseGate** (`gate.ts`): Checks operational IDs (userId, householdId, memberId, email, etc.), free text (label, notes, name), cohort sizes, rare cells, reconstruction/differencing risk, and provenance. Risk score calculation with configurable threshold. Generates audit log entries.

15. **PrivacyTransformPipeline** (`pipeline.ts`): Multi-stage transform: validate no operational IDs → validate no free text → map taxonomy → generalize timestamps → build anonymous fact. Batch processing with acceptance/rejection tracking. Rare cell suppression by taxonomy+month group.

16. **TaskTaxonomyService** (`taxonomy.ts`): Versioned deterministic mapping (v1.0.0). French and English keyword matching with accent normalization. First-match-wins with longest-match priority. Fallback category. No randomness, no ML, no network.

17. **Analytics types** (`types.ts`): `AnonymousTaskFact`, `AnonymousHouseholdAggregate`, `AnonymousCohortAggregate`, `ResearchDataProduct` contain ZERO operational IDs, ZERO free text, ZERO join keys. Household count only (not ID). Cohort IDs are generated, not operational. Documented forbidden fields list. `ConsentRecord` is an operational service type (not analytics export) with explicit annotation "userId (operational — never exported to analytics)".
