### Backend Operational Adapters

1. **Auth adapter** (`LocalAuthAdapter.ts`): Implements `AuthGateway` with email sign-in, session persist/restore/clear, and auth state listeners. Google/Facebook return `null` — honest, no fake OAuth. Session is in-memory (production would use `SecureStorageGateway`).

2. **Sync adapter** (`LocalSyncAdapter.ts`): Implements `SyncGateway`. `isAvailable() = false` in dev. Tracks pending changes for offline operation. Documents last-write-wins conflict resolution. No simulated network sync.

3. **Invitations** (`LocalInvitationAdapter.ts`): Full CRUD — create, accept, decline, revoke, list pending/household. Expiry validation (7-day window). Status transitions enforced (cannot accept non-pending). Proper error messages.

4. **Billing** (`LocalBillingAdapter.ts`): Provider-agnostic `BillingGateway`. `isAvailable() = false` in dev. `purchase()`/`restorePurchases()` return honest failure messages. Per-household subscription management. Entitlement restoration simulation for testing.

5. **Permissions** (`MemberPermissions.ts`): Role hierarchy OWNER > PAYER > ADMIN > MEMBER with comprehensive permission matrix. `resolvePermissionLevel()` from membership role + payer status. Per-household resolution, never global.

6. **SecureStorage** (`LocalSecureStorageAdapter.ts`): Implements `SecureStorageGateway` with set/get/delete/clear — functional.

7. **Push notifications** (`LocalNotificationAdapter.ts`): Behind honest `NotificationGateway`. `isAvailable() = false` in dev. `scheduleNotification()` throws when not configured. No simulated push.

8. **Calendar** (`LocalCalendarAdapter.ts`): Behind honest `CalendarGateway`. `isAvailable() = false` in dev. `createEvent()` returns null. No fake calendar events.

### Research Analytics Plane

9. **Query budget** (`queryBudget.ts`): Rate limits per minute (10) and per day (500), max dimensions per query (3), max time range (24 months), min cohort size (5). Sliding window for per-minute limiting. Daily reset. Custom configuration supported.

10. **Differential privacy** (`differentialPrivacy.ts`): Laplace mechanism `noise = -scale * sign(u) * ln(1 - 2*|u|)` (correct inverse CDF). Gaussian mechanism `sigma = sensitivity * sqrt(2 * ln(1.25/delta)) / epsilon` (correct (ε,δ)-DP formula). Box-Muller transform for Gaussian sampling. Budget tracking with configurable epsilon/delta. Array noise addition. Budget reset.

11. **Consent policy** (`consentPolicy.ts`): Four jurisdiction policies (EU-GDPR, US-CCPA, CH-DSG, UK-GDPR) with purpose-based consent requirements. EU-GDPR requires explicit consent for research/anonymized data products; US-CCPA uses opt-out model. Consent recording, checking, withdrawal. `canProcessData()` combines policy + consent. Retention periods per jurisdiction. Architecture does not presuppose a single legal basis.

12. **Buyer contracts** (`buyerContracts.ts`): `reIdentificationProhibited`, `redistributionProhibited`, and `commercialUseProhibited` are ALWAYS `true` — hardcoded, not configurable. Audit rights granted. Re-identification reporting required. Purpose validation per contract. Contract revocation supported.

13. **Audit/export log** (`auditLog.ts`): `InMemoryAuditExportLog` records every external release with provenance (pipeline version, taxonomy version, transformations, gate version, differential privacy applied), gate result (approved, violation count, risk score), buyer contract reference, household count, and time range. Query by product or buyer.

14. **PrivacyReleaseGate** (`gate.ts`): Checks operational IDs (userId, householdId, memberId, email, etc.), free text (label, notes, name), cohort sizes, rare cells, reconstruction/differencing risk, and provenance. Risk score with configurable threshold. Generates audit log entries.

15. **PrivacyTransformPipeline** (`pipeline.ts`): Multi-stage transform: validate no operational IDs → validate no free text → map taxonomy → generalize timestamps → build anonymous fact. Batch processing with acceptance/rejection tracking. Rare cell suppression by taxonomy+month group.

16. **TaskTaxonomyService** (`taxonomy.ts`): Versioned deterministic mapping (v1.0.0). French and English keyword matching with accent normalization. Longest-match priority. Fallback category. No randomness, no ML, no network.

17. **Analytics types** (`types.ts`): `AnonymousTaskFact`, `AnonymousHouseholdAggregate`, `AnonymousCohortAggregate`, `ResearchDataProduct` contain ZERO operational IDs, ZERO free text, ZERO join keys. Household count only (not ID). Cohort IDs are generated, not operational. Documented forbidden fields list. `ConsentRecord` is an operational service type (not analytics export) with explicit annotation "userId (operational — never exported to analytics)".
