## 4. Findings

### 4.1 MUST-FIX — Upsell contextuel Année/Depuis le début inaccessible en Free

**Path** : `src/features/household/ScoreScreen.tsx`

**Problème** : En mode Free, les boutons de période Année/Depuis le début sont **désactivés** (`Pressable` avec `onPress={() => !isDisabled && handlePeriodChange(p)}` et icône cadenas). Taper ne fait rien, donc l'upsell contextuel Premium pour Année/Depuis le début est **inaccessible** via l'UI. La carte d'upsell `needsPremium` existe mais est du code mort dans le flux Free normal (seulement atteignable via le cas limite d'un downgrade alors qu'on était sur une période Premium).

**Preuve** : `ScoreScreen.tsx` lignes 170-196 : `const isDisabled = !isPremium && (p === 'year' || p === 'all-time');` et `onPress={() => !isDisabled && handlePeriodChange(p)}`. En Free, `isPremium=false` donc year/all-time sont désactivés ; l'utilisateur ne peut pas les sélectionner, donc `needsPremium` (ligne 69) ne devient jamais vrai par interaction normale. `DESIGN_BRIEF.md` (section Score Free) : « Une action sur archive/Année/Depuis le début ouvre alors seulement l'upsell contextuel. » et `RELEASE_DEFINITION.json` V2-03 : « Année/Depuis le début/archive sont Premium avec upsell contextuel, jamais paywall automatique au lancement. »

**mustFix** : true

**Correction exigée** : Rendre les boutons Année/Depuis le début tappables en Free afin que taper déclenche l'upsell contextuel Premium (passer `needsPremium` / afficher la carte d'upsell) au lieu de les désactiver. Conformément à `DESIGN_BRIEF.md`, ne pas « casser » tout l'écran : conserver les données du mois civil courant visibles tout en présentant l'upsell contextuel pour la période Premium demandée.

**Vérification** : En mode demo-free, taper Année et Depuis le début sur l'écran Score et confirmer que l'upsell contextuel Premium apparaît (et que les soldes/historique du mois courant restent visibles), tandis qu'en demo-premium l'archive complète est affichée. Ajouter/ajuster un test d'acceptation prouvant que l'upsell est atteignable depuis l'UI Free.
