## Findings

### MustFix

**F1 — Native share sheet still does not open on Android (core deliverable broken).**
`src/infrastructure/local/LocalSystemShareAdapter.ts` calls `sharing.shareAsync(text, {mimeType:'text/plain', ...})` passing a plain text string as the `url` parameter. expo-sharing's `shareAsync` requires a **local file URL** (scheme `file`). On Android, `SharingModule.getLocalFileFoUrl` throws `InvalidArgumentException("Only local file URLs are supported...")` for a non-file URI. The try/catch swallows it, the Web Share API fallback is unavailable on native, and `share()` returns `{completed:false}`. The share sheet never opens on the APK. The `jest.setup.js` mock of expo-sharing (`shareAsync` resolves `{action:'shared'}`) masks this real failure, and the added tests only assert `isAvailable()===true` and `typeof result.completed==='boolean'` — they never exercise the native path. This is the central V2-05 deliverable.

**F2 — Visual ShareCard is still dead code.**
`src/ui/components/ShareCard.tsx` is exported from the index but never rendered in any screen. The share flow (`ScoreScreen.handleShareScore`, `AddTaskScreen.handleShare`) uses only `generateShareText`, producing plain text. Acceptance requires "Share cards ChoreScore générées et partageables" (visual cards).

**F3 — Visual evidence gallery still absent.**
DESIGN_BRIEF "Galerie de référence obligatoire" and QUALITY_GATES QG-4 require at least 12 reproducible screens plus an empty/error state. V2-05 requires "preuves visuelles reproductibles des écrans cœur et audit accessibilité complet". No gallery/evidence/screenshot artifacts exist in the candidate diff or repository.

**F4 — WCAG AA contrast still fails for textMuted (and warning).**
`textSecondary` was darkened and now passes AA. But `textMuted` (#7A7A87) still fails AA (3.80–4.23:1) on all surfaces and is used for normal-size text (13px captions, placeholders, delete buttons, notes) which does not qualify for the large-text exemption. `warning` fails at 2.97:1. The contrast test was not extended to cover textMuted/warning as the finding required.

### Fixed

**F5 — False push notification display.**
`app/options/personal.tsx` now derives notification states from `app.services.notifications.isAvailable()` and shows honest "Non configuré"/"Indisponible" values. No fake "Activées" states are displayed. Fixed.
